# برنامج تدريب فريق التسويق والبيع

التدريب في مركز قيادة رمز النظام يتم بثلاث طرق تدخل في تعليمات كل موظف تلقائياً:
1. **القوانين المعتمدة** (قسم الحوكمة): قواعد المهارة الأساسية، يقرؤها كل موظف قبل أي رد.
2. **تخصصات كل موظف:** أُضيف لكل موظف معني إطار المهارة الذي يخصه.
3. **مهام تدريب** على لوحة المهام في غرفة الدمج: تمرين عملي لكل موظف بمؤشر قياس وموعد.

## من يفعل ماذا
| الموظف | دوره في المهارة | الإطار الأساسي |
|---|---|---|
| عبدالرحمن (`rahman`)، مدير التسويق | يملك المهارة، ويقرر الانتقال للمدفوع، ويكتب تقرير القمع الأسبوعي | شروط الانتقال، القمع، ملف الدروس |
| ريما (`rima`) | الرسالة الواحدة، ونصوص متجر التطبيقات وصفحة الهبوط | معادلة القيمة، قواعد الكتابة |
| طلال (`talal`) | الإطلاقات والحملات الموسمية | إطار ORB، العرض الكامل |
| أسيل (`aseel`) | الإحالات والشراكات والمؤثرون المرخّصون | الإحالات، تقييم الشريك |
| ماجد (`majed`) | الإعلانات المدفوعة | سلّم الميزانية، المفاهيم والزوايا، التوسع 20% |
| باسل (`basel`) | صفحة الهبوط وتحويل التجربة لاشتراك | قراءة القمع مرحلة بمرحلة |
| غادة (`ghada`) | الربحية والاحتفاظ | فترة الاسترداد لكل شريحة |
| شهد (`shahad`) | العميل المثالي ولغة التجار | لغة العميل، الشرائح |
| د. راكان (`rakan`) | المراجعة الشهرية للعرض والقنوات | العرض الكامل، إيقاف الخاسر |
| جواهر (`jawaher`) | أعمدة المحتوى، والمجتمع، وروابط الحملات | البحث والمشاركة، الأعمدة الأربعة |
| أنس (`anas`) | الـ Hooks | صيغ الـ Hook الأربع |
| سلطان (`sultan`) | سيناريو الفيديو اليومي | سيناريو 30 ثانية |
| دلال (`dalal`) | البوستات والكابشن | منشور قبل وبعد، ممنوعات أسلوب الآلة |
| لين (`leen`) | التصاميم والمقاطع | الإعلان لا يشبه الإعلان |
| فهد (`fahad`) | الجدولة والنشر والتحليل | إعادة التدوير، ترتيب الروابط بالتحول |
| زياد (`ziyad`) | البحث وإجابات الذكاء الاصطناعي | محتوى البحث، بوابة «ماذا نضيف» |
| سارة (`sara`) | البيع وتفعيل التجارب | العرض الحي، أول رد واتساب |
| روان (`khaled`) | متاجر تطبيقات سلة وزد | صفحة التطبيق |
| هيا (`haya`) | تجربة العميل والمجتمع | توقيت طلب الإحالة والتقييم |
| يزن (`yazan`) | تكلفة الجلب | معادلات تكلفة المشترك |
| لجين (`lujain`) | الامتثال | قواعد النظام السبع |

## التمارين (مهام التدريب)
كل تمرين ينتج شيئاً يُستخدم فعلاً، لا اختباراً نظرياً:

1. **ريما:** أعيدي كتابة وصف «سمّ» في متجر تطبيقات سلة بمعادلة القيمة. المؤشر: نسختان، والفائزة تُعتمد.
2. **أنس:** 12 Hook (3 من كل صيغة) لمقطع العرض الحي. المؤشر: أفضل 3 تُستخدم هذا الأسبوع.
3. **سلطان:** سيناريو 30 ثانية بالجدول المعتمد. المؤشر: يُصوّر خلال 3 أيام.
4. **دلال:** 5 منشورات قبل وبعد، كل منها برابط حملة خاص. المؤشر: نسبة العملاء إلى النقرات لكل منشور.
5. **جواهر:** خطة محتوى أسبوع على الأعمدة الأربعة. المؤشر: 7 قطع، كل منها بحث أو مشاركة.
6. **زياد:** 3 مقالات بحث بجملة «ماذا نضيف». المؤشر: نُشرت ومفحوصة بمهارة البحث.
7. **أسيل:** قائمة 10 شركاء بتقييم البنود الأربعة، والتواصل مع أعلى 3 عبر قنواتهم الرسمية. المؤشر: مكالمة واحدة على الأقل.
8. **أسيل وعبدالله:** تصميم مكافأة الإحالة مع التحقق من ربح الريال في الدقيقة. المؤشر: جدول حساب معتمد.
9. **سارة:** عرض حي على متجر عميل راسلنا. المؤشر: تجربة مفعّلة.
10. **روان:** مراجعة صفحة «سمّ» في متجر تطبيقات سلة وزد. المؤشر: قائمة تحسينات منفذة.
11. **ماجد:** خطة اختبار مدفوع (منصتان، 5 مفاهيم، حد خسارة)، **لا تُشغّل** قبل تحقق شروط الانتقال. المؤشر: خطة معتمدة من عبدالرحمن وعبدالله.
12. **غادة ويزن:** نموذج فترة الاسترداد لكل شريحة. المؤشر: جدول بأرقام حقيقية أو افتراضات معلنة.
13. **طلال:** خطة إطلاق ORB للحملة الموسمية القادمة. المؤشر: قائمة جاهزية مكتملة.
14. **عبدالرحمن:** أول تقرير قمع أسبوعي وملف الدروس. المؤشر: يُرفع كل أحد.
15. **لجين:** مراجعة كل ما سبق على قواعد النظام السبع. المؤشر: لا مخالفة واحدة.

## معيار اجتياز التدريب
- يستطيع الموظف شرح «الرسالة الواحدة» ومعادلة القيمة بمثال من «سمّ».
- مخرجاته تمر من مراجعة لجين (`lujain`) للامتثال ونواف (`nawaf`) للجودة.
- كل مخرج له مؤشر قياس ومسؤول وموعد (قانون الجودة الأول في اللوحة).
