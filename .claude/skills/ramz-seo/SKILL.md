# منظومة SEO لرمز النظام

منظومة تعمل كل يوم بلا إجازة. **لكل مشروع:** 20 كلمة مفتاحية جديدة مبحوثة، و5 مقالات تجتاز بوابة الجودة، وتقرير يومي يُرفع لمركز القيادة. كل مشروع يعمل وحده بفريقه ومهمته المجدولة، فإضافة مشروع عاشر لا تبطئ الأول.

## أين كل شيء
| الشيء | المكان |
|---|---|
| دليل التشغيل اليومي (ما تنفذه المهمة المجدولة خطوة بخطوة) | `references/pipeline.md`، ونسخته العاملة في مستودع Sahal: `seo/PIPELINE.md` |
| إضافة مشروع جديد للمنظومة | `references/new-project.md` |
| الأدوات | Sahal: `seo/tools/suggest.py` (اقتراحات قوقل)، و`registry.py` (سجل الكلمات ومنع التكرار)، و`check_article.py` (بوابة الجودة) |
| إعداد كل مشروع | Sahal: `seo/projects/<id>/config.json` |
| سجل المشاريع | Sahal: `seo/projects.json` |
| الكلمات والمقالات والتقارير | Sahal: `seo/projects/<id>/keywords.csv`، و`articles/<التاريخ>/`، و`reports/<التاريخ>.md` |
| الفريق والحالة في اللوحة | مركز القيادة: فريق `seo_<id>`، و`org.company.seo`، ورسالة يومية في غرفة النقاش، وسطر في نتائج المشروع |

## لماذا 20 كلمة و5 مقالات (لا 20 مقالاً)
قوقل يعاقب «إساءة المحتوى بالجملة» (scaled content abuse): صفحات كثيرة تُنتج لرفع الترتيب بلا فائدة للقارئ، سواء كتبها إنسان أو آلة. العقوبة قد تُسقط الموقع كله. لذلك المنظومة:
- **تبحث كثيراً وتكتب بقدر:** 20 كلمة يومياً تبني خريطة طلب كاملة، و5 مقالات فقط تُكتب من أفضلها.
- **لا تكتب مقالاً بلا قيمة مضافة:** حقل `adds` إلزامي (ما نضيفه ولا يوجد في النتائج الأولى)، والمقال بلا قيمة يُوقف.
- **تمنع التكرار:** سجل موحّد يرفض الكلمة المكررة أو شبه المكررة، وفحص تشابه بين المقالات، ودمج نية مكررة في مقال قائم بدل صفحة جديدة.
- **تمنع الحشو:** فحص كثافة الكلمة، وعبارات أسلوب الآلة الممنوعة، وحد أدنى للعمق.
- **تنشر بانتظام:** 5 يومياً كحد أقصى لكل موقع، لا دفعات ضخمة.
- **لا تخترع:** لا أحجام بحث، ولا أرقام نتائج، ولا شهادات عملاء غير موجودة.

## خط الإنتاج اليومي (لكل مشروع)
```
بذور اليوم ← اقتراحات قوقل ← فرز وتصنيف ← السجل (منع التكرار) ← 20 كلمة جديدة
     ← اختيار 5 (BOFU أولاً، حد مقالين للعنقود) ← فحص أكل الصفحات لبعضها
     ← بحث النتائج + «ماذا نضيف» ← كتابة 5 مقالات ← بوابة الجودة + مراجعة رئيسة التحرير
     ← الربط الداخلي وخريطة العناقيد ← تقرير ← GitHub ← مركز القيادة
```
التفاصيل الكاملة في `references/pipeline.md`.

## التشغيل الذي لا يتوقف
- **التشغيل اليومي:** لكل مشروع مهمة مجدولة يومية (Claude) تعمل حتى لو كان مركز القيادة مغلقاً، وتنفذ `seo/PIPELINE.md`.
- **الصمود:**
  - أي خطوة تفشل تُسجّل وتكمل الباقي.
  - اليوم الفائت يُعوّض ببحث كلمات مضاعف دون مضاعفة المقالات.
  - لا يتكرر عمل يوم مكتمل.
- **الحفظ:** كل يوم في GitHub، فلا يضيع شيء حتى لو تعطل مركز القيادة.
- **المراقبة:**
  - مهند يراجع تقارير كل المشاريع يومياً.
  - يومان متتاليان بلا تقرير لمشروع = عطل يُرفع لزياد وللمالك.

## مؤشرات النجاح (شهرياً لكل مشروع)
| المؤشر | المصدر | الهدف |
|---|---|---|
| كلمات مبحوثة | `keywords.csv` | 600 تقريباً (20 × 30) |
| مقالات اجتازت الجودة | `articles/` | 150 تقريباً (5 × 30) |
| نسبة المقالات الموقوفة | التقارير | أقل من 20%. أعلى من ذلك يعني بذوراً ضعيفة |
| صفحات مفهرسة | Search Console (بعد ربط الموقع) | أكثر من 80% مما نُشر |
| ظهور ونقرات | Search Console | نمو شهري، والكلمات التي في المراكز 5–20 تُحسّن أولاً |
| تجارب وتحويلات من البحث | GA4 + لوحة «سمّ» | الهدف الحقيقي |

بعد ربط الموقع وSearch Console تُضاف خطوة «التحسين»: الصفحات في المراكز 5–20 تُحدَّث قبل كتابة الجديد، والصفحات التي فقدت زياراتها أكثر من 30% تُحدَّث.
